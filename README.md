# College Projects & Labs (2024–2026) 🎓

Архив учебных проектов, курсовых и лабораторных работ, выполненных во время обучения в колледже в период с 2024 по 2026 год.

---

## 📂 Структура репозитория

### 🎓 2 Курс
* **`2Курс/БД_...`** — лабораторные и практические работы по базам данных (PostgreSQL, MS SQL).
* **`2Курс/РПМ_...`** — разработка программных модулей (C#, Windows Forms, алгоритмы).
* **`2Курс/JAKKU2_...`** — практические работы по программированию на C#.

### 🚀 3 Курс
* **`3Курс/ОсновыАлг_...`** — основы алгоритмизации и структуры данных (C++ / C#).
* **`3Курс/JekaCrypto_...`** — работы по алгоритмам шифрования и криптографии.

### 💻 Основные проекты
* **`CodeLearn`** — образовательная веб-платформа с интерактивным обучением и AI-помощником.
* **`DemoExam`** — проект демонстрационного экзамена по компетенции "Разработка ПО" (C# / WPF / EF).
* **`TourAgents`** — веб-приложение для туристического агентства (ASP.NET Core Blazor).
* **`Sport`** — информационная система учета спортивных секций (C# / WinForms).
* **`WordAIAgent`** — AI-ассистент и плагин для Microsoft Word с поддержкой локальных LLM (Ollama).
* **`OllamaAI`** — инструменты интеграции и инсталляторы для локального запуска Ollama.
* **`Kursach_Program`** — программная часть курсовой работы.
* **`Hotel`** — система управления отелем (Desktop GUI + CLI интерфейс).
* **`Game`** — игровой проект на C++.
* **`NeiPan`** — прикладной проект / утилита.
* **`Perdej_MathTrainer`** — тренажер математических вычислений.
* **`BlazorApp`** — веб-приложение на ASP.NET Core Blazor.
* **`FutureLabs`** — лабораторные работы с графикой и анимацией (C#, Visual Basic).
* **`LabaBond1`**, **`Laba4`**, **`Laba6`**, **`Laba7Da`**, **`Laba8Da`**, **`ГотовыеЛабы_Lab8`** — сборники лабораторных работ.
* **`Virus`** — учебный исследовательский проект (C++ / WinAPI).
