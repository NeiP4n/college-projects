# 🤖 Word AI Agent — VSTO Add-in для MS Word + Ollama

Полнофункциональный AI-агент для Microsoft Word, интегрированный с локальной LLM через Ollama.

## 🚀 Установка

### Шаг 1: Требования
- **Visual Studio 2022** с компонентом "Office/SharePoint Development"
- **Microsoft Word 2016/2019/365**
- **.NET Framework 4.7.2**
- **Ollama** запущенный локально

### Шаг 2: Установка Ollama
```bash
# Windows — скачать с https://ollama.ai
# Запустить с доступом со всех интерфейсов:
set OLLAMA_HOST=0.0.0.0
ollama serve

# Скачать модель (выберите одну):
ollama pull llama3           # Рекомендуется — хороший баланс
ollama pull mistral          # Лёгкий и быстрый
ollama pull codellama        # Если нужна работа с кодом
ollama pull qwen2.5          # Отличный для русского языка
```

### Шаг 3: Добавление зависимости Newtonsoft.Json

В Visual Studio → Package Manager Console:
```
Install-Package Newtonsoft.Json
```

Или добавьте вручную в .csproj:
```xml
<PackageReference Include="Newtonsoft.Json" Version="13.0.3" />
```

### Шаг 4: Настройка проекта в VS 2022

1. Откройте `WordAIAgent.csproj`
2. ПКМ на проекте → Properties → Office → Start browser with URL: (оставьте пустым)
3. В свойствах проекта убедитесь, что Target Framework = .NET 4.7.2
4. Добавьте MainRibbon.xml как **Embedded Resource**:
   - ПКМ на файле → Properties → Build Action: **Embedded Resource**

### Шаг 5: Сборка и запуск

```
Build → Build Solution (Ctrl+Shift+B)
Debug → Start Debugging (F5)
```

Word откроется с вашим Add-in.

### 🤖 AI Агент (Чат с Ollama)

- **Чат в реальном времени** с историей диалога
- **Контекст документа** — AI видит ваш документ
- **Автовыполнение команд** — AI управляет Word через JSON
- **18 готовых быстрых команд** в интерфейсе

### ⚡ Автоматические команды (JSON)

AI может ответить командой, и она выполнится автоматически:

```json
// Вставить текст
{"action": "InsertText", "params": {"text": "Привет, мир!"}}

// Создать заголовок
{"action": "CreateHeading", "params": {"level": 1}}

// Создать таблицу
{"action": "CreateTable", "params": {"rows": 3, "cols": 4}}

// Форматирование
{"action": "Bold", "params": {"enabled": true}}
{"action": "AlignCenter", "params": {}}
{"action": "FontSize", "params": {"size": 14}}
```

## ⚙ Настройки

В форме настроек (⚙ кнопка):

- **Хост Ollama**: по умолчанию `http://0.0.0.0:11434`
- **Модель**: выбор из всех установленных моделей
- **Температура**: 0.0 (точно) — 2.0 (творчески)  
- **Макс. токенов**: лимит ответа (100—8192)
- **Системный промпт**: инструкции для AI агента

## 🔧 Устранение проблем

**Ошибка "Не удалось подключиться":**
```bash
# Убедитесь что Ollama запущен:
ollama serve
# Проверьте доступность:
curl http://localhost:11434/api/tags
```

**Word не видит Add-in:**
1. Visual Studio → Build → Rebuild Solution
2. Проверьте что VSTO runtime установлен
3. Откройте Word → Файл → Параметры → Надстройки

**Add-in заблокирован:**
```
Файл → Параметры → Центр управления безопасностью →
Параметры центра управления безопасностью →
Надстройки → разрешить надстройки от разработчиков
```
