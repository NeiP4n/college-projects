# Как работает программа CodeLearn

## 1. Что это за программа

CodeLearn - это учебный сайт для изучения программирования.

Пользователь заходит на сайт, регистрируется или входит в аккаунт, видит карту обучения, выбирает модуль, проходит уроки и может запускать код прямо в браузере.

## 2. Из чего состоит программа

Программа сделана как сайт на ASP.NET Core MVC.

Главные части:

- `Controllers` - принимают запросы от пользователя.
- `Views` - показывают страницы сайта.
- `Models` - описывают данные программы.
- `Services` - выполняют отдельную логику, например вход, регистрацию и отправку email.
- `Data/AppDbContext.cs` - связывает программу с базой данных.
- `wwwroot` - хранит CSS, JavaScript, картинки, шрифты и другие файлы для внешнего вида сайта.

## 3. Как программа запускается

Сначала выполняется файл `Program.cs`.

В нем программа:

1. Подключает MVC, чтобы работали контроллеры и страницы.
2. Подключает базу данных PostgreSQL.
3. Настраивает регистрацию и вход через ASP.NET Identity.
4. Подключает вход через Google.
5. Включает сессии, чтобы временно хранить данные регистрации.
6. Включает защиту: HTTPS, cookies, заголовки безопасности и ограничение частых запросов.
7. Запускает маршрут по умолчанию: сначала открывается страница входа.

## 4. Как работает вход

Когда пользователь открывает сайт, он попадает на страницу входа.

Если пользователь вводит email и пароль:

1. `AccountController` получает данные формы.
2. `AuthService` ищет пользователя в базе.
3. Если пароль правильный, программа входит в аккаунт.
4. В базу добавляется запись о входе за сегодняшний день.
5. Пользователь переходит на главную страницу.

Если данные неправильные, сайт показывает ошибку.

## 5. Как работает регистрация

Обычная регистрация проходит так:

1. Пользователь вводит email и пароль.
2. Программа проверяет, что email еще не занят.
3. Создается код из 6 цифр.
4. Код отправляется на email.
5. Email, пароль и код временно сохраняются в сессии.
6. Пользователь вводит код.
7. Если код правильный, пользователь выбирает никнейм и аватар.
8. После этого аккаунт создается в базе данных.
9. Пользователь автоматически входит на сайт.

Код действует 10 минут.

## 6. Как работает вход через Google

Пользователь может войти через Google.

Программа делает так:

1. Перенаправляет пользователя на Google.
2. Google возвращает email, id пользователя и аватар.
3. Если такой пользователь уже есть, сайт сразу входит в аккаунт.
4. Если пользователя еще нет, сайт просит выбрать никнейм.
5. После выбора никнейма создается новый аккаунт.

## 7. Главная страница

Главная страница находится в `MainController`.

На ней показываются:

- никнейм пользователя;
- аватар;
- серия дней входа подряд;
- общее количество дней, когда пользователь заходил;
- карта модулей обучения.

Серия дней считается по таблице `LoginRecords`.

Например, если пользователь заходил сегодня, вчера и позавчера, серия равна 3.

## 8. Как устроены курсы и уроки

В программе есть модули обучения.

Модуль - это большая тема на карте.

У каждого модуля есть:

- название;
- описание;
- порядок;
- состояние: открыт или закрыт;
- позиция на карте;
- цвет;
- список уроков.

Урок - это отдельная страница внутри модуля.

У урока есть:

- название;
- порядок;
- состояние: открыт или закрыт;
- блоки контента.

Блок контента - это часть урока.

Типы блоков могут быть разные:

- текст;
- задание;
- код;
- тест;
- кнопка.

## 9. Как пользователь открывает курс

Когда пользователь нажимает на модуль:

1. Срабатывает `CourseController`.
2. Программа ищет модуль в базе.
3. Загружает уроки этого модуля.
4. Проверяет, какие уроки пользователь уже прошел.
5. Показывает страницу курса.

## 10. Как пользователь проходит урок

Когда пользователь открывает урок:

1. Срабатывает `LessonController`.
2. Программа находит урок по `id`.
3. Загружает все блоки урока по порядку.
4. Проверяет, прошел ли пользователь этот урок раньше.
5. Показывает страницу урока.

Когда пользователь заканчивает урок:

1. JavaScript отправляет POST-запрос.
2. Программа добавляет запись в `UserLessonCompletion`.
3. Если запись уже есть, новая не создается.

Так программа понимает, какие уроки уже завершены.

## 11. Как работает запуск кода

В программе есть API `api/run`.

Оно нужно, чтобы пользователь мог запускать код из урока.

Поддерживаются:

- C#;
- Python.

Как это работает:

1. Браузер отправляет код и язык программирования.
2. Программа проверяет, что код не пустой и не слишком длинный.
3. Если язык C#, код запускается через Roslyn.
4. Если язык Python, создается временный `.py` файл и запускается Python.
5. Программа возвращает результат: вывод, ошибку и время выполнения.

На выполнение дается 5 секунд.

## 12. Как работает конструктор

В проекте есть конструктор курсов.

Он состоит из:

- `BuilderController` - показывает страницу конструктора;
- `BuilderApiController` - изменяет данные через API;
- `wwwroot/js/builder/builder.js` - JavaScript для работы конструктора;
- `wwwroot/css/builder/builder.css` - стили конструктора.

Через конструктор можно:

- создавать модули;
- менять модули;
- удалять модули;
- менять позицию модуля на карте;
- создавать уроки;
- менять уроки;
- удалять уроки;
- создавать блоки урока;
- менять блоки;
- удалять блоки;
- менять порядок модулей, уроков и блоков.

## 13. Как работает база данных

База подключается через `AppDbContext`.

В базе есть основные таблицы:

- `Users` - пользователи;
- `LoginRecords` - дни входа пользователя;
- `Modules` - учебные модули;
- `Lessons` - уроки;
- `ContentBlocks` - блоки внутри уроков;
- `LessonCompletions` - пройденные уроки.

Также есть таблицы Identity:

- роли;
- claims;
- логины;
- токены.

Они нужны для авторизации.

## 14. Что происходит при удалении

Если удалить модуль, его уроки не удаляются полностью.

У уроков просто очищается ссылка на модуль.

Если удалить урок, его блоки тоже не удаляются полностью.

У блоков очищается ссылка на урок.

Это сделано, чтобы случайно не потерять данные.

## 15. Простая схема работы

Пользователь открывает сайт.

Потом:

1. Входит или регистрируется.
2. Попадает на главную карту.
3. Выбирает модуль.
4. Открывает список уроков.
5. Проходит урок.
6. При необходимости запускает код.
7. После завершения урок помечается как пройденный.
8. Прогресс сохраняется в базе данных.

## 16. Самое главное

Если очень коротко:

CodeLearn - это сайт, где пользователь учится по модулям и урокам. Данные хранятся в PostgreSQL. Вход и регистрация сделаны через Identity и Google. Прогресс уроков сохраняется в базе. Курсы можно редактировать через конструктор. Код из уроков можно запускать прямо на сайте.
